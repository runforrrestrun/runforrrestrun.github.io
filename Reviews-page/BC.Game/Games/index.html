BC.GAME Crash

Crash is a multiplier game in which the result increases until the round ends. Players must decide when to cash out, with later cash-outs offering potentially larger multipliers but also a greater risk of losing the wager.

BC.GAME publishes a fairness explanation stating that its Crash results are derived from a pre-generated chain of 10 million hashes. Each hash corresponds to a round, and the results are released in reverse order. The platform provides a verification method using SHA-256, allowing players to examine the relationship between hashes and generated multipliers.

This system is intended to make the predetermined sequence verifiable. It does not remove the house edge or make any particular multiplier more likely to occur.

BC.GAME Mines

Mines allows players to reveal tiles while avoiding mines hidden on the board. The outcome depends on the generated arrangement of safe positions and mines.

According to BC.GAME's published fairness documentation, the game uses HMAC-SHA256 with a server seed, client seed and nonce to generate a hash. That hash is then processed to determine the arrangement used for the round.

BC.GAME Plinko

Plinko uses a ball-drop format in which the ball travels through a series of pegs before reaching a result position. Different landing positions correspond to different outcomes.

The platform's fairness documentation describes an HMAC-SHA512 calculation using the client seed, nonce and server seed. The resulting hash is divided into groups that determine whether the ball moves left or right at successive stages.

BC.GAME Dice, Limbo and Wheel

Classic Dice, Limbo and Wheel also have published fairness calculation methods. Classic Dice converts part of an HMAC-SHA256 result into a numerical dice outcome, while Wheel uses the generated hash to select a result segment. Limbo uses a hash-derived value to calculate a multiplier.

Although these games use cryptographic verification, they have different mechanics and mathematical distributions. Players should consult each game's fairness documentation rather than assuming the same calculation applies to every original title.
