Are DuelBits Games Provably Fair?

DuelBits publishes provably fair verification methods for selected original games. Provably fair technology uses cryptographic information to help players verify that a game's outcome matches its published result-generation process.

Rather than relying exclusively on an operator's statement that a game is fair, players can use the relevant seeds, hashes and round information to reproduce or check certain outcomes.

The exact algorithm differs between games, so the verification process should be considered individually rather than assuming that every casino title uses the same system.

Server Seed, Client Seed and Nonce

The supplied DuelBits technical documentation describes three important inputs used by games such as Dice and Plinko:

  • Server seed: A cryptographically generated value produced by the game server.
  • Client seed: A value that the player can customise.
  • Nonce: A counter associated with the sequence of rounds or bets.

In the documented verification process, a hashed server seed can be displayed before the underlying seed is revealed. After the seed is changed or disclosed according to the game's rules, previous results can be checked against the published algorithm.

DuelBits Dice Verification

DuelBits Dice uses a server seed, client seed and nonce to generate a ticket.

The platform publishes an example calculation using SHA-256, allowing players to compare a reproduced ticket with the recorded game result.

DuelBits Plinko Verification

Plinko uses a similar seed-based system, but its ticket values are mapped to outcome ranges associated with the game's pockets.

The supplied documentation describes ticket values from 0 to 65,534 and explains how those values determine the resulting pocket.

Duel Poker Verification

Duel Poker uses a different method involving a public seed, server seed and nonce.

The supplied documentation states that seeds are generated daily at 00:00 UTC. DuelBits publishes a hashed server seed before revealing the underlying value, allowing players to check historical rounds.

Does Provably Fair Mean Players Cannot Lose?

No. Provably fair verification does not guarantee winnings or remove the mathematical advantage built into a gambling game.

Its purpose is to provide transparency about the generation of supported outcomes. It does not independently establish the fairness of every third-party game, the operator's financial position or the outcome of account disputes.
