RTP and Volatility

Two useful statistics when comparing TrustDice slots are RTP and volatility.

RTP, or Return to Player, represents the theoretical percentage of wagered money that a game is designed to return over a very large number of rounds. It does not predict what will happen during one spin or one playing session.

Volatility describes how wins tend to be distributed. Higher-volatility slots generally pay less frequently but can produce larger individual wins, while lower-volatility games tend to produce smaller wins more often.

TrustDice also provides Live RTP information for supported games. The supplied material states that the Live RTP database updates every 10 minutes and can be filtered by factors including RTP, popularity, provider, volatility and release date.

Live RTP should still be interpreted as historical performance data rather than a prediction of the next result. A game showing a high recent return is not guaranteed to continue paying at the same rate.

How TrustDice Provably Fair Games Work

Provably fair verification is one of the main differences between TrustDice Originals and conventional third-party casino games.

The system uses cryptographic information associated with each result. The supplied TrustDice material describes three important components:

  • Server Seed: A value generated by the game system.
  • Client Seed: A value associated with the player or browser session.
  • Nonce: A counter that changes as additional bets are placed.

A cryptographic hash can be used to commit to the server seed before the result is revealed. Once the necessary information becomes available, the completed result can be checked against the committed data.

This makes it possible to verify that a completed result corresponds with the cryptographic information associated with the round. Provably fair verification does not, however, allow the next result to be predicted and does not remove the game's house edge.
